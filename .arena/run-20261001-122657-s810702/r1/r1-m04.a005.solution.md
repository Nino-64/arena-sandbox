# Orbital: a one-button neon arcade game

Orbital is a single self-contained `index.html` (about 1,750 lines, 83 KB). It uses vanilla Canvas 2D, Web Audio and localStorage, with no libraries, no build step and no network requests. Save the file below and open it in a browser. It runs from `file://`, offline, or from any static host.

**The loop:** your comet orbits a glowing core and **one input reverses its direction**. Grab shards in quick succession to build a chain and raise your multiplier (up to x8). Dodge meteors coming in from off-screen. Slip through the gap in the shockwaves the core sends out. The spawners check each other, so a meteor is never sent across a shockwave's safe gap: every death is avoidable with the one input you have. The speed, spawn rate and music tempo all rise with time. When you die, a single tap starts the next run in about a second.

## Run it

1. Copy the full source at the bottom into a file named `index.html`.
2. Double-click it, or serve the folder (`npx serve .`) and open the URL.
3. Click **PLAY**. The browser only allows audio after your first click, tap or key press, so sound starts then.

## Controls

| Action | Keyboard | Mouse / touch |
| --- | --- | --- |
| Reverse orbit | `Space`, arrow keys, `A` `D` `W` `S` `Z` `X` | Click / tap anywhere on the field |
| Pause / resume | `P` or `Esc` | Pause button (top right) |
| Restart run | `R` (playing or paused) | Pause menu, then Restart |
| Retry after death | `Space`, `Enter` or `R` | Tap anywhere on the result card |
| Mute all | `M` | Settings |

## Scoring and progression

| Event | Points (x multiplier) |
| --- | --- |
| Survive | 10 per second |
| Shard | 25, extends chain; every 5 chained shards adds +1 multiplier, up to x8 |
| Near miss with a meteor ("CLOSE") | 15, adds 1 s to the chain timer |
| Pass a shockwave through its gap ("THREADED") | 40, adds 1.5 s to the chain timer |

The chain breaks if 2.6 s pass with no shard. Power-ups show up on the ring every 13 to 19 s: **Shield** absorbs one hit, **Magnet** pulls nearby shards for 7 s, **Slow-mo** runs hazards at half speed for 5 s. Difficulty reaches its cap at 150 s.

**What is saved** (localStorage key `orbital.save`): best score, best time, total shards, runs played, XP, peak multiplier, equipped skin and settings.

- **Rank:** every point you score is also XP. Rank *r* needs 400·(r−1)² XP. The bar fills on the result screen and a fanfare plays when you rank up.
- **Unlockable skins (7):**

| Skin | How to unlock |
| --- | --- |
| Ion | Unlocked from the start |
| Ember | Score 2,500 in one run |
| Verdant | Collect 150 shards in total |
| Nova | Reach a x6 multiplier |
| Aurum | Play 40 runs |
| Void | Score 10,000 in one run |
| Prism | Score 25,000 in one run (rainbow trail) |

Unlocks are **worked out from your stats** each time rather than stored, so they always match your progress.

## How each requirement is met

| Requirement | Implementation |
| --- | --- |
| 1. Self-contained, instant restart | One HTML file with no dependencies. Death plays a 0.8 s slow-mo explosion, then the result card. Tap, `Space` or `R` starts a new run. `R` also restarts in the middle of a run. |
| 2. Juice | Trauma-based screen shake and a zoom punch. A 130 ms hit-stop and slow-mo on death. White or colored screen flashes. A pooled particle system (800 particles) with additive glow sprites. Ripples, a comet trail, a squash on reverse, pop-in shards, floating score text, a pulsing core whose hue shifts with difficulty, off-screen meteor warning arrows, and an animated multiplier badge, score count-up and rank bar. |
| 3. Procedural Web Audio | Every sound is synthesized: oscillators, a shared noise buffer, filters and a compressor. Shard pickups climb a pentatonic scale as your chain grows. There are separate sounds for multiplier, near miss, thread, power-up, shield break, death and fanfare. A lookahead-scheduled music loop (Am–F–C–G: bass, kick, hats, arpeggio) speeds up and opens its filter as intensity rises. Sound effects and music have separate toggles, plus a volume slider. |
| 4. Save system | Versioned and validated localStorage save. It holds high score, XP and rank, total shards, runs and peak multiplier (which drive the 7 unlockable skins), the equipped skin and settings. It is saved the moment you die, so closing the tab right after a death loses nothing. |

## Technology choice

| Option (score 1 to 5) | Self-contained / offline | Load and failure risk | Control over feel | Code size for this scope | Total |
| --- | --- | --- | --- | --- | --- |
| **Vanilla Canvas 2D + Web Audio** | 5 | 5 | 5 | 4 | **19** |
| Phaser 3 via CDN | 2 (needs network or a ~1 MB inline bundle) | 3 | 4 | 4 | 13 |
| Three.js via CDN | 2 | 3 | 4 | 2 | 11 |
| React + bundler | 1 (needs a build) | 3 | 3 | 2 | 9 |

I'm about 85% confident vanilla Canvas is the best fit. The game is 2D, a single arena, and needs at most a few hundred sprites, so an engine adds download weight and a failure point (a CDN outage, or opening the file offline) without adding capability. React was rejected, so the React/bundler guidance does not apply.

## What happens when things go wrong

| Situation | Behaviour |
| --- | --- |
| localStorage blocked (private mode, sandboxed iframe) | The game still runs. A warning toast appears and the menu shows a note that progress lasts only for this tab. |
| Save is not valid JSON | The raw text is copied to `orbital.save.corrupt`, a fresh save starts, and a toast says so. |
| Save has wrong types, NaN or out-of-range values, an unknown skin, or missing fields | Each field is checked and clamped on its own, and you are told the save was repaired. A locked skin falls back to Ion. |
| Save written by a newer version | Loaded **read-only**, so it is never overwritten by the old format. |
| Storage full or failing on write | Saving stops with a visible warning, and the result card shows "Not saved". |
| Two tabs open | The `storage` event **merges** the other tab's progress (best, XP, shards, runs, peak, best time take the larger value), so neither tab overwrites the other. Its settings and skin are **queued** while you are mid-run and adopted at a safe point (death, restart, menu), with the audio graph and settings UI resynced. A progress reset carries an `epoch` counter, so it propagates to other tabs instead of being undone by their merge. |
| No Web Audio, or audio throws | The game runs silently. Settings says audio is unavailable, and audio errors are logged once and never stop play. |
| Tab hidden or window loses focus | Auto-pause and the audio is suspended. On resume, play ramps from 25% speed back to full over 0.7 s so you are not dropped straight into a hit. |
| Long frame stall | Frame delta is capped at 0.1 s with a fixed 120 Hz simulation, so hazards cannot skip past the player. |
| Panic taps at death | Retry ignores input for 320 ms after the card appears. Clicks on menus that are fading out are ignored (`pointer-events:none` plus state checks). |
| Any uncaught error in the game | The loop stops and a "Something broke" panel shows the stack trace and a Reload button, so the game never keeps running in a broken state. Errors from browser extensions are ignored. |

Shake and flash strength have a setting (0 to 100%) that also scales the zoom punch. When the OS asks for reduced motion it defaults to **0** (no shake, no zoom punch, no full-screen flash) and the player can opt back in. At 0 or under reduced motion, the hard on/off blinking of expiring pickups, invulnerability and warning arrows is replaced by a slow, soft pulse. Full-screen flashes are capped at 45% opacity at any setting. The layout handles phones (safe-area insets, `touch-action:none`, DPR capped at 2) and resizing or rotation.

## Fairness: no unavoidable deaths

The player has one input and is locked to the ring, so a shockwave's safe gap and a meteor crossing that same arc at the same moment would be a death the player could not avoid. The two hazard spawners prevent this:

- **Meteor spawn:** each candidate path is sampled every 20 ms across each pending shockwave's danger window, from 0.9 s before it lands (time to travel to the gap) to 0.35 s after. A path is rejected if it ever enters the band of the ring the player can touch over the gap arc, padded by 0.42 rad plus the meteor's angular size. It retries 10 times, then skips that meteor rather than spawn an unfair one.
- **Aimed meteors pause** while a shockwave is about to land. Reaching the gap is the challenge in that moment.
- **Shockwave spawn:** it tries up to 16 gap positions and picks one that no meteor already in flight will cover. If none is clear, the wave is postponed 0.6 s.
- Slow-mo slows meteors and shockwaves by the same factor, so the prediction holds at either speed.

**Measured** (headless Chromium, 25 simulated minutes at maximum difficulty, random play, counting shockwaves where a meteor was physically inside the safe gap's band during that window):

| Build | Shockwaves | With a meteor inside the gap | Meteors spawned |
| --- | --- | --- | --- |
| Without the check | 339 | 252 (74%) | 4,219 |
| With the check | 224 | **0** | 4,241 |

The cost is about a third fewer shockwaves at maximum difficulty, because waves are postponed until a clear gap exists. Meteor pressure is unchanged. I'm about 90% confident no unavoidable meteor-and-gap combination remains. The leftover risk is a meteor sitting *between* the player and a far gap when the wave lands. The 0.42 rad padding and the pause on aimed meteors make that rare, and the player can still choose a route.

## Assumptions

- "Self-contained" means one file with no external assets. I also left out web fonts and used a system UI font stack, because a missing font would be one more thing that could fail.
- "Progression" means account-level progress across runs: rank/XP and stat-gated skins. It does not mean a level campaign.
- The named skills are not installed, so I read their intent as: a polished visual design, complete code with no TODOs, and React guidance only if React were used (it is not).

## How it was tested

I tested in headless Chromium 141 (Playwright) at 1280×800, 1024×700 and 390×844:
- Played many runs with random clicks and key presses. Death, the result card, retry and `Space` retry all worked.
- Pause and resume with `Esc`.
- Shockwaves, shield, magnet, slow-mo and the Prism rainbow trail, all forced on.
- Hangar lock and progress bars, and rank-up.
- An invalid-JSON save, a save with bad types and values, and blocked localStorage.
- **Fairness:** the Monte Carlo run described above.
- **Two tabs** in one browser context: tab B changed the volume and wrote a higher best while tab A was mid-run. A kept its volume during the run, merged the best score at once, then adopted B's volume when it died, and its commit kept B's volume. A reset in B was propagated to A through the epoch (best went to 0).
- **Reduced motion** (`reducedMotion: 'reduce'` context): a fresh save defaults shake and flash to 0.

No console errors appeared and the error panel never showed. The game held about 58 fps (headless, software rendering). ESLint `no-undef` was clean, with no errors (the only warnings are unused `catch` parameters).

**Not tested:**
- **Audio by ear.** The sound code ran with no errors, but I could not listen to it.
- **Safari and Firefox.** The code uses only standard APIs, with a `webkitAudioContext` fallback for older Safari, but those paths were not run.

Medium-high confidence they work; check those browsers first if you deploy.

  function setIntensity(v) { mus.intensity = clamp(v, 0, 1); }

  return {
    unlock, suspend, apply, startMusic, stopMusic, setIntensity, sfx,
    get available() { return !failed; },
    get running() { return !!ctx && ctx.state === 'running'; },
  };

const rgbCache = new Map();
function hexRgb(hex) {
  let v = rgbCache.get(hex);
  if (v) return v;
  const m = /^#([0-9a-f]{6})$/i.exec(hex);
  const n = m ? parseInt(m[1], 16) : 0xffffff;
  v = [(n >> 16) & 255, (n >> 8) & 255, n & 255];
  rgbCache.set(hex, v);
  return v;
}
function hueHex(h) {
  // HSL(h, 85%, 66%) -> hex, hue quantised to 15deg so the glow-sprite cache stays tiny
  h = ((Math.round(h / 15) * 15) % 360 + 360) % 360;
  const sat = 0.85, lig = 0.66, a = sat * Math.min(lig, 1 - lig);
  const f = n => {
    const k = (n + h / 30) % 12;
    const c = lig - a * Math.max(-1, Math.min(k - 3, 9 - k, 1));
    return Math.round(255 * c).toString(16).padStart(2, '0');
  };
  return '#' + f(0) + f(8) + f(4);
}
const glowCache = new Map();
function glowSprite(hex) {
  let c = glowCache.get(hex);
  if (c) return c;
  if (glowCache.size > 96) glowCache.clear();
  const [r, g, b] = hexRgb(hex);
  c = document.createElement('canvas'); c.width = c.height = 64;
  const x = c.getContext('2d');
  const gr = x.createRadialGradient(32, 32, 0, 32, 32, 32);
  gr.addColorStop(0, `rgba(${r},${g},${b},1)`);
  gr.addColorStop(0.2, `rgba(${r},${g},${b},0.55)`);
  gr.addColorStop(0.5, `rgba(${r},${g},${b},0.14)`);
  gr.addColorStop(1, `rgba(${r},${g},${b},0)`);
  x.fillStyle = gr; x.fillRect(0, 0, 64, 64);
  glowCache.set(hex, c);
  return c;
}
function glow(hex, x, y, radius, alpha) {
  if (alpha <= 0.002) return;
  ctx.globalAlpha = Math.min(1, alpha);
  ctx.drawImage(glowSprite(hex), x - radius, y - radius, radius * 2, radius * 2);
}

/* ---------- spawning ---------- */
function freeRingAngle(minFromPlayer, minFromOthers) {
  for (let tries = 0; tries < 12; tries++) {
    const a = G.theta + (Math.random() < 0.5 ? -1 : 1) * rand(minFromPlayer, Math.PI);
    const others = [...G.gemsOnRing, ...G.powerups];
    if (others.every(o => Math.abs(angDiff(o.a, a)) > minFromOthers)) return a;
  }
  return G.theta + Math.PI; // fallback: opposite side, always valid
}
function spawnGem() {
  if (G.gemsOnRing.length >= 3) return;
  G.gemsOnRing.push({ a: freeRingAngle(0.9, 0.45), life: 8, max: 8, born: 0 });
}
function spawnPower() {
  if (G.powerups.length) return;
  const types = ['shield', 'magnet', 'slow'];
  G.powerups.push({ a: freeRingAngle(1.2, 0.5), type: types[Math.floor(Math.random() * types.length)], life: 7, max: 7, born: 0 });
}
/* ---------- fairness: a meteor may never cover a shockwave's safe gap ----------
   One input cannot both stay inside a gap and dodge a meteor crossing that same
   arc, so the two spawners check each other. Meteors and pulses are both slowed
   by the Slow-mo power-up by the same factor, so their timing ratio is stable and
   the prediction holds in either speed. */
const PULSE_SPEED = 118;
const FAIR_ARC = 0.42;     // extra radians around the gap that must stay clear
const FAIR_BEFORE = 0.9;   // seconds before the pulse lands (time to reach the gap)
const FAIR_AFTER = 0.35;   // seconds after it lands
function pulseArrival(p) { return (R - p.r) / PULSE_SPEED; }
// Samples the meteor's straight-line path across the pulse's danger window and reports
// whether it is ever inside the band of the ring the player can touch, over the gap arc.
// Sampling (rather than solving for crossing points) also catches near-tangent paths
// that stay in the band for a long time.
function conflicts(x, y, vx, vy, r, pulse) {
  if (pulse.resolved) return false;
  const tp = pulseArrival(pulse);
  if (tp < -FAIR_AFTER) return false;
  const band = r + PLAYER_HIT_R + 4;
  const angPad = pulse.half + FAIR_ARC + Math.atan2(r + PLAYER_HIT_R, R);
  for (let t = Math.max(0, tp - FAIR_BEFORE); t <= tp + FAIR_AFTER; t += 0.02) {
    const mx = x + vx * t, my = y + vy * t;
    if (Math.abs(Math.hypot(mx, my) - R) < band && Math.abs(angDiff(Math.atan2(my, mx), pulse.gap)) < angPad) return true;
  }
  return false;
}
const meteorUnfair = (x, y, vx, vy, r) => G.pulses.some(p => conflicts(x, y, vx, vy, r, p));
// True while a shockwave will reach the ring soon enough that the player must be heading for its gap.
const pulseImminent = () => G.pulses.some(p => !p.resolved && pulseArrival(p) < FAIR_BEFORE + 0.4);

function spawnMeteor() {
  const d = G.diff;
  const spawnR = Math.max(430, Math.hypot(view.hw, view.hh) + 40);
  const speed = rand(125, 175) + 150 * d;
  const r = rand(10, 18) + (Math.random() < 0.15 ? 8 : 0);
  // 45% aim where the player will be, the rest cross the ring at random.
  // No aimed meteors while a shockwave is about to land: the gap is the challenge then.
  const aimed = Math.random() < 0.45 && !pulseImminent();
  for (let tries = 0; tries < 10; tries++) {
    const from = Math.random() * TAU;
    const sx = Math.cos(from) * spawnR, sy = Math.sin(from) * spawnR;
    let tx, ty;
    if (aimed && tries < 5) {
      const eta = spawnR / speed;
      const a = G.theta + G.dir * G.omega * eta * rand(0.6, 1.0) + rand(-0.5, 0.5);
      tx = Math.cos(a) * R; ty = Math.sin(a) * R;
    } else {
      const a = Math.random() * TAU, rr = rand(0, R + 40);
      tx = Math.cos(a) * rr; ty = Math.sin(a) * rr;
    }
    const dx = tx - sx, dy = ty - sy, len = Math.hypot(dx, dy) || 1;
    const vx = dx / len * speed, vy = dy / len * speed;
    if (meteorUnfair(sx, sy, vx, vy, r)) continue;
    const verts = [];
    for (let i = 0; i < 9; i++) verts.push(rand(0.72, 1.08));
    G.meteors.push({ x: sx, y: sy, vx, vy, r, rot: Math.random() * TAU, spin: rand(-2, 2), verts, near: false, awarded: false, prevD: Infinity, dead: false });
    return true;
  }
  // Every candidate would cover a safe gap: skip this one rather than spawn an unfair hit.
  G.fairSkips++;
  return false;
}
function spawnPulse() {
  const d = G.diff;
  const half = lerp(0.66, 0.42, d);
  // Pick the gap whose arc no meteor already in flight will cross around landing time.
  let best = null, bestBad = Infinity;
  for (let tries = 0; tries < 16; tries++) {
    const gap = G.theta + rand(-2.0, 2.0);
    const probe = { r: 30, gap, half, resolved: false };
    const bad = G.meteors.reduce((n, m) => n + (!m.dead && conflicts(m.x, m.y, m.vx, m.vy, m.r, probe) ? 1 : 0), 0);
    if (bad < bestBad) { best = gap; bestBad = bad; }
    if (bad === 0) break;
  }
  if (bestBad > 0) { G.tPulse = 0.6; G.fairSkips++; return false; } // try again shortly instead of an unfair wave
  G.pulses.push({ r: 30, gap: best, half, resolved: false, hit: false });
  Sound.sfx.pulse();
  G.coreBeat = 1;
  return true;
}

function flip() {
  if (G.state !== 'playing') return;
  G.dir *= -1;
  G.squash = 1;

}

function hurt(source) {
  if (G.state !== 'playing' || G.invuln > 0) return;
  const [x, y] = playerPos();

    G.shield = false; G.invuln = 1.25;

    Sound.sfx.shield();

  }
  die();
}

/* ---------- end of run: commit progression immediately ---------- */
let lastResult = null;
function finishRun() {
  const d = save();
  const before = unlockedIds(d);
  const prevBest = d.best, prevXp = d.xp;
  const score = Math.floor(G.score);
  d.runs = Math.min(MAX_INT, d.runs + 1);
  d.totalGems = Math.min(MAX_INT, d.totalGems + G.gems);
  d.xp = Math.min(MAX_INT, d.xp + score);
  d.maxMult = Math.max(d.maxMult, G.maxMult);
  d.bestTime = Math.max(d.bestTime, G.time);
  const newBest = score > prevBest;
  if (newBest) d.best = score;
  const saved = Store.commit();
  const after = unlockedIds(d);
  lastResult = {
    score, newBest: newBest && prevBest > 0, gems: G.gems, time: G.time, maxMult: G.maxMult,
    prevXp, xp: d.xp, rankBefore: rankOf(prevXp), rankAfter: rankOf(d.xp),
    unlocked: SKINS.filter(s => after.has(s.id) && !before.has(s.id)),
    saved,
  };
}

/* =====================================================================
   8. Simulation (fixed step)
   ===================================================================== */
function update(dt) {
  const playing = G.state === 'playing';
  const hz = G.slowT > 0 ? 0.5 : 1; // slow power-up affects hazards only

  if (G.state === 'menu') {
    G.theta += G.dir * 1.6 * dt;
    G.menuFlipT -= dt;
    if (G.menuFlipT <= 0) { G.dir *= -1; G.menuFlipT = rand(1.5, 3.5); G.squash = 1; }
  }

  if (playing) {
    G.time += dt;
    G.diff = Math.min(1, G.time / 150);
    G.omega = 2.1 + 1.5 * G.diff;
    G.theta = (G.theta + G.dir * G.omega * dt) % TAU;
    G.score = Math.min(MAX_INT, G.score + 10 * dt * G.mult);
    G.invuln = Math.max(0, G.invuln - dt);
    G.magnetT = Math.max(0, G.magnetT - dt);
    G.slowT = Math.max(0, G.slowT - dt);
    Sound.setIntensity(G.diff * 0.8 + (G.mult - 1) / 7 * 0.2);

    if (G.comboT > 0) {
      G.comboT -= dt;
      if (G.comboT <= 0) {
        if (G.combo >= 5) { const [x, y] = playerPos(); floatText(x, y - 20, 'CHAIN BROKEN', '#8d95bb', 13); Sound.sfx.comboLost(); }
        G.combo = 0; G.mult = 1; G.comboT = 0;
      }
    }

    // spawn timers
    G.tMeteor -= dt * hz;
    if (G.tMeteor <= 0) { spawnMeteor(); G.tMeteor = lerp(1.5, 0.42, G.diff) * rand(0.7, 1.3); if (G.diff > 0.5 && Math.random() < 0.25) spawnMeteor(); }
    G.tPulse -= dt * hz;
    if (G.tPulse <= 0) { if (spawnPulse()) G.tPulse = lerp(9, 4.2, G.diff) * rand(0.85, 1.15); }
    G.tPower -= dt;
    if (G.tPower <= 0) { spawnPower(); G.tPower = rand(13, 19); }
    G.tGem -= dt;
    if (G.gemsOnRing.length < 2 || (G.tGem <= 0 && G.gemsOnRing.length < 3)) { spawnGem(); G.tGem = rand(1.2, 2.2); }
  }

  const [px, py] = playerPos();

  // shards
  for (let i = G.gemsOnRing.length - 1; i >= 0; i--) {
    const g = G.gemsOnRing[i];
    g.born += dt;
    if (!playing) continue;
    g.life -= dt;
    if (G.magnetT > 0) {
      const da = angDiff(G.theta, g.a);
      if (Math.abs(da) < 1.6) g.a += Math.sign(da) * Math.min(Math.abs(da), 3.2 * dt);
    }
    const gx = Math.cos(g.a) * R, gy = Math.sin(g.a) * R;
    if (Math.hypot(gx - px, gy - py) < GEM_PICK_R) {
      G.gemsOnRing.splice(i, 1);
      G.gems++;
      bumpCombo();
      addScore(25, gx, gy - 16, '', currentSkin().color);
      burst(gx, gy, currentSkin().color, 16, 220, 0.55, 3);
      burst(gx, gy, '#ffffff', 6, 140, 0.4, 2);
      ripple(gx, gy, currentSkin().color, 34, 0.35, 2);
      Fx.punch = Math.max(Fx.punch, 0.012);
      Sound.sfx.gem(G.combo);
      continue;
    }
    if (g.life <= 0) { G.gemsOnRing.splice(i, 1); burst(gx, gy, '#5a6288', 6, 60, 0.4, 2); }
  }

  // power-ups
  for (let i = G.powerups.length - 1; i >= 0; i--) {
    const u = G.powerups[i];
    u.born += dt;
    if (!playing) continue;
    u.life -= dt;
    const ux = Math.cos(u.a) * R, uy = Math.sin(u.a) * R;
    if (Math.hypot(ux - px, uy - py) < GEM_PICK_R + 2) {
      G.powerups.splice(i, 1);
      const col = POWER_COLORS[u.type];
      if (u.type === 'shield') G.shield = true;
      if (u.type === 'magnet') G.magnetT = 7;
      if (u.type === 'slow') G.slowT = 5;
      floatText(ux, uy - 20, POWER_NAMES[u.type], col, 17);
      burst(ux, uy, col, 30, 260, 0.7, 3);
      ripple(ux, uy, col, 70, 0.5, 3);
      Fx.doFlash(0.18, col);
      Sound.sfx.power();
      continue;
    }
    if (u.life <= 0) G.powerups.splice(i, 1);
  }

  // meteors
  for (let i = G.meteors.length - 1; i >= 0; i--) {
    const m = G.meteors[i];
    const k = (G.state === 'playing' ? hz : 1) * dt;
    m.x += m.vx * k; m.y += m.vy * k; m.rot += m.spin * k;
    if (Math.random() < 0.35) particle(m.x + rand(-m.r, m.r) * 0.4, m.y + rand(-m.r, m.r) * 0.4, -m.vx * 0.15 + rand(-20, 20), -m.vy * 0.15 + rand(-20, 20), 0.45, 2.2, '#ff7a45', 2);
    const dist = Math.hypot(m.x - px, m.y - py);
    if (playing && !m.dead) {
      if (dist < m.r + PLAYER_HIT_R) { hurt({ kind: 'meteor', m }); if (G.state !== 'playing') break; }
      else {
        if (dist < m.r + 30) m.near = true;
        if (m.near && !m.awarded && dist > m.prevD) {
          m.awarded = true;
          addScore(15, px, py - 24, 'CLOSE', '#ff9f6b');
          G.comboT = Math.max(G.comboT, Math.min(COMBO_TIME, G.comboT + 1.0));
          Fx.shake(0.06);
          Sound.sfx.near();
        }
      }
    }
    m.prevD = dist;
    const out = Math.hypot(m.x, m.y) > Math.max(500, Math.hypot(view.hw, view.hh) + 90) && (m.x * m.vx + m.y * m.vy) > 0;
    if (m.dead || out) G.meteors.splice(i, 1);
  }

  // pulses (expanding rings with a safe gap)
  for (let i = G.pulses.length - 1; i >= 0; i--) {
    const p = G.pulses[i];
    p.r += PULSE_SPEED * dt * (G.state === 'playing' ? hz : 1);
    if (playing && !p.resolved) {
      const inGap = Math.abs(angDiff(G.theta, p.gap)) < p.half;
      if (Math.abs(p.r - R) < 6 && !inGap && G.invuln <= 0) { p.resolved = true; p.hit = true; hurt({ kind: 'pulse' }); if (G.state !== 'playing') break; }
      else if (p.r > R + 8) {
        p.resolved = true;
        if (!inGap) continue; // passed only thanks to invulnerability: no reward
        addScore(40, px, py - 24, 'THREADED', '#7dffb0');
        G.comboT = Math.max(G.comboT, Math.min(COMBO_TIME, G.comboT + 1.5));
        Sound.sfx.thread();
        ripple(px, py, '#7dffb0', 40, 0.4, 2);
      }
    }
    if (p.r > Math.hypot(view.hw, view.hh) + 40) G.pulses.splice(i, 1);
  }

  // trail sampling
  if (G.state === 'playing' || G.state === 'menu') {
    G.trail.unshift([px, py]);
    if (G.trail.length > 26) G.trail.length = 26;
  } else if (G.trail.length) {
    G.trail.pop();
  }
}

function updateFx(dt) {
  for (const p of parts) {
    if (!p.alive) continue;
    p.life -= dt;
    if (p.life <= 0) { p.alive = false; continue; }
    const k = Math.exp(-p.drag * dt);
    p.vx *= k; p.vy *= k;
    p.x += p.vx * dt; p.y += p.vy * dt;
  }
  for (let i = texts.length - 1; i >= 0; i--) { const t = texts[i]; t.life -= dt; t.y -= 34 * dt; if (t.life <= 0) texts.splice(i, 1); }
  for (let i = ripples.length - 1; i >= 0; i--) { const r = ripples[i]; r.life -= dt; if (r.life <= 0) ripples.splice(i, 1); }
  G.squash = Math.max(0, G.squash - dt * 6);
  G.coreBeat = Math.max(0, G.coreBeat - dt * 2);
}

const POWER_COLORS = { shield: '#7cf7ff', magnet: '#ffd166', slow: '#c3b0ff' };
const POWER_NAMES = { shield: 'SHIELD', magnet: 'MAGNET', slow: 'SLOW-MO' };
const stars = Array.from({ length: 220 }, () => ({ a: Math.random() * TAU, d: Math.sqrt(Math.random()) * 950, z: rand(0.25, 1), tw: Math.random() * TAU }));

// Comfort mode (OS reduced motion, or shake/flash turned off): no hard on/off flicker,
// only a slow, soft pulse, so "about to expire" and "invulnerable" stay readable.
const calm = () => prefersReduced || save().settings.shake < 0.05;
const blinkA = (tsec, freq) => calm()
  ? 0.6 + 0.3 * Math.sin(tsec * 5)
  : (Math.sin(tsec * freq) > 0 ? 1 : 0.35);

function render(now) {
  const { w, h, dpr, scale } = view;
  const tsec = now / 1000;
  ctx.setTransform(1, 0, 0, 1, 0, 0);
  ctx.globalCompositeOperation = 'source-over';
  ctx.globalAlpha = 1;
  ctx.fillStyle = '#05060f';
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  if (backdrop) ctx.drawImage(backdrop, 0, 0, canvas.width, canvas.height);

  const sh = Fx.trauma * Fx.trauma * 18;
  const sx = (Math.random() * 2 - 1) * sh, sy = (Math.random() * 2 - 1) * sh;
  const k = dpr * scale * (1 + Fx.punch * save().settings.shake);
  ctx.setTransform(k, 0, 0, k, dpr * (w / 2 + sx), dpr * (h / 2 + sy));

  const sk = currentSkin();
  const coreHue = 190 + 140 * G.diff;

  // stars (slow parallax rotation)
  ctx.fillStyle = '#cfd8ff';
  const rot = tsec * 0.02;
  for (const s of stars) {
    const a = s.a + rot * s.z;
    const x = Math.cos(a) * s.d, y = Math.sin(a) * s.d;
    ctx.globalAlpha = (0.25 + 0.45 * s.z) * (0.7 + 0.3 * Math.sin(tsec * 2 + s.tw));
    const sz = 0.6 + s.z * 1.3;
    ctx.fillRect(x, y, sz, sz);
  }

  ctx.globalCompositeOperation = 'lighter';

  // orbit ring
  ctx.globalAlpha = 0.22;
  ctx.strokeStyle = '#8fa2ff';
  ctx.lineWidth = 1.5;
  ctx.beginPath(); ctx.arc(0, 0, R, 0, TAU); ctx.stroke();
  ctx.globalAlpha = 0.07; ctx.lineWidth = 10;
  ctx.beginPath(); ctx.arc(0, 0, R, 0, TAU); ctx.stroke();

  // pulse safe-gap markers on the ring
  for (const p of G.pulses) {
    if (p.resolved) continue;
    const near = clamp(1 - (R - p.r) / (R - 30), 0, 1);
    ctx.globalAlpha = 0.25 + 0.55 * near;
    ctx.strokeStyle = '#7dffb0'; ctx.lineWidth = 6; ctx.lineCap = 'round';
    ctx.beginPath(); ctx.arc(0, 0, R, p.gap - p.half, p.gap + p.half); ctx.stroke();
  }

  // core
  const beat = 1 + 0.08 * Math.sin(tsec * 4) + 0.35 * G.coreBeat;
  const coreCol = hueHex(coreHue);
  glow(coreCol, 0, 0, 90 * beat, 0.55);
  glow('#ffffff', 0, 0, 34 * beat, 0.5);
  ctx.globalAlpha = 0.8; ctx.strokeStyle = coreCol; ctx.lineWidth = 2;
  for (let i = 0; i < 3; i++) {
    const a0 = tsec * (0.8 + i * 0.5) * (i % 2 ? -1 : 1) + i * 2;
    ctx.beginPath(); ctx.arc(0, 0, 20 + i * 7, a0, a0 + 1.6); ctx.stroke();
  }
  // combo timer arc around core
  if (G.state === 'playing' && G.comboT > 0) {
    ctx.globalAlpha = 0.9; ctx.strokeStyle = sk.color; ctx.lineWidth = 3; ctx.lineCap = 'round';
    ctx.beginPath(); ctx.arc(0, 0, 48, -Math.PI / 2, -Math.PI / 2 + TAU * (G.comboT / COMBO_TIME)); ctx.stroke();
  }

  // pulses
  for (const p of G.pulses) {
    const fade = clamp(1 - (p.r - R) / 260, 0, 1) * (p.hit ? 0.4 : 1);
    if (fade <= 0) continue;
    const a0 = p.gap + p.half, a1 = p.gap - p.half + TAU;
    ctx.strokeStyle = '#ff4d6d'; ctx.lineCap = 'round';
    ctx.globalAlpha = 0.18 * fade; ctx.lineWidth = 16;
    ctx.beginPath(); ctx.arc(0, 0, p.r, a0, a1); ctx.stroke();
    ctx.globalAlpha = 0.95 * fade; ctx.lineWidth = 4;
    ctx.beginPath(); ctx.arc(0, 0, p.r, a0, a1); ctx.stroke();
  }

  // shards
  for (const g of G.gemsOnRing) {
    const x = Math.cos(g.a) * R, y = Math.sin(g.a) * R;
    const pop = Math.min(1, g.born * 5);
    const s = (1 - Math.pow(1 - pop, 3)) * (1 + 0.1 * Math.sin(tsec * 6 + g.a));
    const blink = g.life < 2 ? blinkA(tsec, 22) : 1;
    glow(sk.color, x, y, 30 * s, 0.6 * blink);
    ctx.save();
    ctx.translate(x, y); ctx.rotate(tsec * 2 + g.a); ctx.scale(s, s);
    ctx.globalAlpha = blink; ctx.fillStyle = '#ffffff';
    ctx.beginPath(); ctx.moveTo(0, -9); ctx.lineTo(6.5, 0); ctx.lineTo(0, 9); ctx.lineTo(-6.5, 0); ctx.closePath(); ctx.fill();
    ctx.restore();
  }

  // power-ups
  for (const u of G.powerups) {
    const x = Math.cos(u.a) * R, y = Math.sin(u.a) * R, col = POWER_COLORS[u.type];
    const pop = Math.min(1, u.born * 4), s = (1 - Math.pow(1 - pop, 3)) * (1 + 0.12 * Math.sin(tsec * 5));
    const blink = u.life < 2 ? blinkA(tsec, 22) : 1;
    glow(col, x, y, 40 * s, 0.7 * blink);
    ctx.save(); ctx.translate(x, y); ctx.scale(s, s);
    ctx.globalAlpha = blink; ctx.strokeStyle = col; ctx.lineWidth = 2.2; ctx.lineCap = 'round'; ctx.lineJoin = 'round';
    ctx.beginPath(); ctx.arc(0, 0, 14, 0, TAU); ctx.stroke();
    ctx.strokeStyle = '#ffffff'; ctx.beginPath();
    if (u.type === 'shield') { for (let i = 0; i <= 6; i++) { const a = i / 6 * TAU + Math.PI / 6; i ? ctx.lineTo(Math.cos(a) * 7, Math.sin(a) * 7) : ctx.moveTo(Math.cos(a) * 7, Math.sin(a) * 7); } }
    else if (u.type === 'magnet') { ctx.arc(0, 1, 6, Math.PI, 0, false); ctx.moveTo(-6, 1); ctx.lineTo(-6, -5); ctx.moveTo(6, 1); ctx.lineTo(6, -5); }
    else { ctx.moveTo(-5, -7); ctx.lineTo(5, -7); ctx.lineTo(-5, 7); ctx.lineTo(5, 7); ctx.closePath(); }
    ctx.stroke(); ctx.restore();
  }

  // meteors
  for (const m of G.meteors) {
    glow('#ff5a3c', m.x, m.y, m.r * 3, 0.45);
    ctx.save(); ctx.translate(m.x, m.y); ctx.rotate(m.rot);
    ctx.globalCompositeOperation = 'source-over';
    ctx.globalAlpha = 1; ctx.fillStyle = '#1b1324'; ctx.strokeStyle = '#ff7a59'; ctx.lineWidth = 2; ctx.lineJoin = 'round';
    ctx.beginPath();
    for (let i = 0; i < m.verts.length; i++) {
      const a = i / m.verts.length * TAU, rr = m.r * m.verts[i];
      i ? ctx.lineTo(Math.cos(a) * rr, Math.sin(a) * rr) : ctx.moveTo(Math.cos(a) * rr, Math.sin(a) * rr);
    }
    ctx.closePath(); ctx.fill(); ctx.stroke();
    ctx.restore();
    ctx.globalCompositeOperation = 'lighter';
  }

  // ripples
  for (const r of ripples) {
    const t = 1 - r.life / r.max, e = 1 - Math.pow(1 - t, 3);
    ctx.globalAlpha = (1 - t) * 0.8; ctx.strokeStyle = r.color; ctx.lineWidth = r.width * (1 - t) + 0.5;
    ctx.beginPath(); ctx.arc(r.x, r.y, 4 + r.maxR * e, 0, TAU); ctx.stroke();
  }

  // player trail + head
  const alive = G.state === 'playing' || G.state === 'menu' || G.state === 'paused';
  if (G.trail.length > 1) {
    ctx.lineCap = 'round';
    for (let i = 1; i < G.trail.length; i++) {
      const t = 1 - i / G.trail.length;
      ctx.globalAlpha = t * 0.85; ctx.strokeStyle = skinTrailColor(i); ctx.lineWidth = 1 + t * 9;
      ctx.beginPath(); ctx.moveTo(G.trail[i - 1][0], G.trail[i - 1][1]); ctx.lineTo(G.trail[i][0], G.trail[i][1]); ctx.stroke();
    }
  }
  if (alive) {
    const [x, y] = playerPos();
    const blink = G.invuln > 0 ? blinkA(tsec, 40) : 1;
    const sq = 1 + 0.5 * G.squash;
    glow(sk.color, x, y, 38 * sq, 0.8 * blink);
    ctx.globalAlpha = blink; ctx.fillStyle = '#ffffff';
    ctx.beginPath(); ctx.arc(x, y, 7 * (1 + 0.25 * G.squash), 0, TAU); ctx.fill();
    if (G.shield) {
      ctx.globalAlpha = 0.85; ctx.strokeStyle = POWER_COLORS.shield; ctx.lineWidth = 2;
      ctx.beginPath();
      for (let i = 0; i <= 6; i++) { const a = i / 6 * TAU + tsec * 2; const px2 = x + Math.cos(a) * 17, py2 = y + Math.sin(a) * 17; i ? ctx.lineTo(px2, py2) : ctx.moveTo(px2, py2); }
      ctx.stroke();
    }
    if (G.magnetT > 0) {
      ctx.globalAlpha = 0.25 + 0.15 * Math.sin(tsec * 10); ctx.strokeStyle = POWER_COLORS.magnet; ctx.lineWidth = 6;
      ctx.beginPath(); ctx.arc(0, 0, R, G.theta - 1.6, G.theta + 1.6); ctx.stroke();
    }
  }

  // particles
  for (const p of parts) {
    if (!p.alive) continue;
    const t = p.life / p.max;
    glow(p.color, p.x, p.y, p.size * 2.6 * (0.4 + 0.6 * t), t);
  }

  // floating text
  ctx.globalCompositeOperation = 'source-over';
  ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
  for (const t of texts) {
    const age = 1 - t.life / t.max;
    const sc = age < 0.15 ? 0.6 + (age / 0.15) * 0.6 : 1.2 - Math.min(0.2, (age - 0.15));
    ctx.globalAlpha = clamp(t.life / 0.35, 0, 1);
    ctx.font = `800 ${(t.size * sc).toFixed(1)}px ${FONT}`;
    ctx.fillStyle = 'rgba(5,6,15,0.6)'; ctx.fillText(t.text, t.x + 1.2, t.y + 1.5);
    ctx.fillStyle = t.color; ctx.fillText(t.text, t.x, t.y);
  }

  // off-screen meteor warnings
  ctx.globalCompositeOperation = 'lighter';
  const ex = view.hw - 18, ey = view.hh - 18;
  for (const m of G.meteors) {
    if (Math.abs(m.x) < view.hw && Math.abs(m.y) < view.hh) continue;
    if (m.x * m.vx + m.y * m.vy > 0) continue; // leaving, no warning
    const f = Math.min(ex / Math.max(1e-6, Math.abs(m.x)), ey / Math.max(1e-6, Math.abs(m.y)));
    const ix = m.x * f, iy = m.y * f, ang = Math.atan2(m.y, m.x);
    ctx.save(); ctx.translate(ix, iy); ctx.rotate(ang);
    ctx.globalAlpha = calm() ? 0.85 : 0.6 + 0.4 * Math.sin(tsec * 16);
    ctx.fillStyle = '#ff5a3c';
    ctx.beginPath(); ctx.moveTo(8, 0); ctx.lineTo(-6, -7); ctx.lineTo(-3, 0); ctx.lineTo(-6, 7); ctx.closePath(); ctx.fill();
    ctx.restore();
  }

  // screen-space overlays
  ctx.setTransform(1, 0, 0, 1, 0, 0);
  if (Fx.flash > 0.01) {
    ctx.globalCompositeOperation = 'lighter';
    ctx.globalAlpha = Math.min(0.45, Fx.flash * 0.5); ctx.fillStyle = Fx.flashColor; // capped: never a full white-out
    ctx.fillRect(0, 0, canvas.width, canvas.height);
  }
  if (G.slowT > 0) {
    ctx.globalCompositeOperation = 'source-over';
    ctx.globalAlpha = Math.min(1, G.slowT) * 0.12; ctx.fillStyle = '#6a4cff';
    ctx.fillRect(0, 0, canvas.width, canvas.height);
  }
  ctx.globalCompositeOperation = 'source-over';
  ctx.globalAlpha = 1;
  if (vignette) ctx.drawImage(vignette, 0, 0, canvas.width, canvas.height);
}

let last = performance.now(), acc = 0;
function frame(now) {
  if (halted) return;
  requestAnimationFrame(frame);
  try {
    let rdt = (now - last) / 1000;
    last = now;
    if (!(rdt > 0)) rdt = 0;
    rdt = Math.min(rdt, 0.1); // a long stall must not teleport hazards through the player

    Fx.update(rdt);
    let scale = 1;
    if (G.state === 'paused') scale = 0;
    else if (G.state === 'dying' || G.state === 'over') scale = G.timeScale;
    if (G.state === 'playing' && G.resumeRamp > 0) { G.resumeRamp = Math.max(0, G.resumeRamp - rdt); scale = lerp(1, 0.25, G.resumeRamp / 0.7); }
    if (G.hitstop > 0) { G.hitstop -= rdt; scale = 0; }
    if (G.state === 'dying' || G.state === 'over') G.timeScale = Math.min(1, G.timeScale + rdt * 0.5);

    acc += rdt * scale;
    let n = 0;
    while (acc >= STEP && n < 16) { update(STEP); updateFx(STEP); acc -= STEP; n++; }
    if (n >= 16) acc = 0;
    if (scale === 0 && G.state !== 'paused') updateFx(rdt * 0.2);

    if (G.state === 'dying') {
      G.dyingT += rdt;
      if (G.dyingT > 0.8) { G.state = 'over'; UI.showOver(); }
    }
    if (G.state === 'playing') UI.updateHud();
    render(now);
  } catch (err) {
    fatal(err);
  }
}
