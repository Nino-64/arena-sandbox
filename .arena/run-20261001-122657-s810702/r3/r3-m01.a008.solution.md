# Orbit Snap: a one-button arcade game in a single HTML file

**Orbit Snap** is a one-button arcade game. Your core circles a pulsing singularity on one of two orbits. Tap, click or press Space to snap to the other orbit. Grab gold shards to build a combo multiplier (up to x8), dodge red mines, and leave a mine's orbit at the last moment for **Close Call** bonuses. The game speeds up every 18 seconds. One hit ends the run, and you can be playing again 0.4 s later.

**To run it:** save the file below as `index.html` and open it in any current browser. It needs no build step, no server, no dependencies and no network access. It works with a mouse, a keyboard or a touchscreen.

## Controls

| Action | Mouse / touch | Keyboard |
|---|---|---|
| Start a run (title screen) | *Play* button, or tap the canvas | `Space`, `Enter` |
| Switch orbit | Tap / click anywhere | `Space`, `Enter`, `↑`, `↓`, `W`, `S` (letter keys work with Caps Lock or Shift too) |
| Retry after death | Tap anywhere, from 0.4 s after the hit (during the death slow-motion or on the result card) | `Space`, `Enter`, `R` (same timing) |
| Restart mid-run | Pause → Restart | `R` |
| Pause / resume | Pause button | `Esc`, `P` (the game also pauses automatically when the tab loses focus) |
| Mute | Speaker button | `M` (the setting is saved) |
| Menus | Click / tap | `Tab` moves between buttons; `Space` / `Enter` press the focused button; `Esc` closes the Hangar |

On the menu and the result card, `Space` / `Enter` start a run only when no other button has focus. If you Tab to *Hangar* or *Menu*, those keys press that button instead. The result card focuses *Play again* when it opens, so a single `Space` still retries.

## How the four requirements are met

1. **Self-contained, with instant restart.** Everything is in one file: inline CSS, inline JS, and system fonts. From 0.4 s after the hit, any tap, `Space`, `Enter` or `R` starts a new run straight away. If you press during the slow-motion death, the result card is skipped (the run is already saved; a new best still gets a "New best!" toast). If you don't press, the result card appears at 0.85 s and the same input retries from it. The 0.4 s guard is there because the tap that killed you is often followed by another rhythm tap; without it that tap would throw away the run summary. `R` restarts at any time during play, and the run you leave still banks its score and shards.
2. **Juice.** The game uses trauma-based screen shake (shake grows with the square of trauma, and includes rotation). It also has:
   - hit-stop on death, shield breaks and close calls;
   - a slow-motion death sequence;
   - additive glow particles (up to 700 at once, using cached glow sprites);
   - shockwave rings, a full-screen flash, and floating score text;
   - squash and stretch when the core snaps between orbits;
   - a skin-coloured motion trail and a core that pulses with the music's kick drum;
   - a "SPEED UP" phase banner that pops inside the singularity, and a background colour that changes with each phase;
   - a starfield that drifts as you orbit;
   - pop animations on the score and the multiplier, and achievement toasts;
   - phone vibration when you die.
3. **Sound (Web Audio, fully synthesized).** No audio files are used. Collecting a shard plays a note on a rising pentatonic scale, so a long combo plays a melody. Other sounds:
   - an arpeggio when the multiplier goes up;
   - a filtered-noise whoosh for close calls;
   - shield up and shield break sounds;
   - a layered noise and sub-bass death sound;
   - a phase-up fanfare;
   - UI, purchase and denied blips.

   A procedural music loop (kick, hi-hat and pentatonic bass) runs on a look-ahead scheduler, and its tempo rises with the phase (112 to 150 BPM). Everything passes through a compressor, so stacked sounds don't clip.
4. **Save system (LocalStorage).** The save stores your best score, best combo, shard bank, number of runs, lifetime shards, owned cores, equipped core, unlocked achievements and the mute setting. It lives under one versioned key (`orbitsnap.save.v1`). Values are checked when loaded, and a corrupt save falls back to defaults. The save is built so progress is not lost without you knowing:
   - **Saved at the moment of death.** The run is written to storage in the same frame you are hit, before the ~1 s slow-motion sequence. Closing the tab during the death animation loses nothing. A run you abandon with `R`, *Restart*, *Menu*, or by closing the page mid-run also banks its score and shards.
   - **Blocked storage is reported.** At startup the game test-writes to storage. If storage is blocked (some private windows, or site data disabled), or a later write fails (quota full), the menu and the result card show a red notice: *"Saving is blocked in this browser… your progress lasts until this tab closes"*. A one-time toast also appears if saving fails mid-session. The game stays fully playable in memory.
   - **Safe with two tabs open.** Every change (end of run, purchase, achievement, mute) re-reads the save before writing it. The `storage` event also pulls in changes from other tabs right away, including into an open Hangar. A core bought in one tab is never undone by a run that ends in another. A run in progress keeps the core and the mute state it started with: if you equip *Void* or press mute in another tab, this tab's comet does not change colour mid-run and its sound does not cut out. Both changes take effect when the run ends. The bank and owned cores are still adopted at once, so nothing is written back stale.
   - **Can't be farmed by quitting.** The *Runs* total (and the "Gravity Habit" achievement for 25 runs) counts every death, but an abandoned run counts only if it lasted at least 5 seconds. Pressing `R` 25 times in a row adds nothing to *Runs*. The shards and score of a short abandoned run are still banked, because you did earn them.

   **Progression:** each shard you collect also goes into your bank. You spend the bank in the **Hangar** on 6 cores (Ion is free; Ember 120, Toxin 300, Orchid 650, Aurora 1,200 with a rainbow trail, and Void 2,500). There are also **9 achievements** that pay bonus shards (Overdrive for reaching x8, Daredevil for 10 close calls, Singularity for 3,000 points, and others).

## A worked example: what happens in one run, and why it stays fair

These are real numbers on a 390×844 phone. The orbit radii are 0.22 and 0.37 of the play-field unit (here 390 px, the screen width), so the inner orbit is 86 px and the outer is 144 px. Phase 1 speed is 1.9 rad/s, so one lap takes about 3.3 s.

- **0–1.3 s:** The first pattern appears ahead of you. A hazard pops in at least 2.4 rad ahead, which at phase 1 is **1.26 s** before you reach it. Later pieces of a pattern appear together with its first piece, so they give you even longer. For example, a *pair* pattern puts three shards on the outer orbit and one mine on the inner orbit, opposite the middle shard.
- **Tap:** Your core moves between orbits over 0.09 s. Each object is checked once, in the frame your angle passes it. Collision uses your *actual* tweened radius: you count as "on" an orbit once you are past the halfway radius. A mid-snap hit or miss therefore always matches what you see on screen.
- **Shard 1–7:** Each shard is worth 10 points and adds 1 to the combo. At 8 combo the multiplier becomes x2, then x3 at 16, and so on up to x8. If you pass a shard on the other orbit, the combo resets. That is the greed hook: shards often sit next to mines.
- **Close call:** You get 25 × multiplier points, a small hit-stop and a whoosh when your core *actually leaves a mine's orbit* (crosses the halfway radius) less than 0.22 s before reaching that mine. The game records the last orbit you left and when you left it. Pressing two keys at once, or tapping with two fingers, flips the lane and flips it back before the core moves, so it earns nothing. A mine on the orbit you were never on earns nothing either. Only a late dodge, which really risks a hit, pays.
- **18 s:** Phase 2 starts. Speed rises by 0.17 rad/s. The singularity shows "SPEED UP" with the new phase number popping. The colours change, the tempo rises, and harder patterns join the pool (*wall*, *zigzag*).

The main thing this example showed: if patterns were spaced by angle, higher speeds would squeeze a slalom into gaps no human can hit. So **every gap is measured in seconds of travel**, not radians. Gaps start at 0.42 s and shrink to a minimum of 0.25 s. Reading time works the same way. Hazards appear `max(2.4 rad, 1.15 s × speed)` ahead, capped at 4.3 rad. The cap is needed because the orbit is only 2π around: a hazard 4.3 rad ahead is drawn 2 rad *behind* you, clear of the trail and of the 0.6 rad zone where passed objects fade out. At the top speed of 3.7 rad/s (phase 12+) the look-ahead is 4.26 rad, still under the cap. **Reading time never drops below 1.15 s:**

| Phase | Speed (rad/s) | Look-ahead (rad) | Reading time |
|---|---|---|---|
| 1 | 1.90 | 2.40 (floor) | 1.26 s |
| 3 | 2.24 | 2.58 | 1.15 s |
| 6 | 2.75 | 3.16 | 1.15 s |
| 12+ | 3.70 (max) | 4.26 | 1.15 s |

So the game gets harder through faster rhythm and tighter gaps, never through an impossible layout or less than 1.15 s to read one. I checked this with an automated bot that only dodges mines (its code is in "What I tested" below). It survived 100 s from a fresh start (it reached phase 6). It also survived 40 s with the game forced straight to phase 12 at full speed. The bot also logged the shortest time between a hazard appearing and the player reaching it: 1.13 s. That is the 1.15 s floor minus up to one frame of measurement lag.

## Trade-offs I chose, and what each one costs

| Decision | Why | What it costs |
|---|---|---|
| **Plain Canvas 2D + plain JS in one file** (no Phaser, Three.js or React) | You get exactly what you asked for: open the file and play. No CDN to break, no build, about 70 KB. A one-button 2D game doesn't need a physics engine or a scene graph. | No engine tools (tilemaps, a physics engine, an asset loader). Adding a big new system means writing it yourself. React best practices don't apply because React isn't used. |
| **Menus and HUD are HTML on top of the canvas** | Real buttons give keyboard focus, screen-reader labels, crisp text and CSS transitions for free. Global shortcuts step aside when a button has focus, so `Space`/`Enter` always do what the focused button says. | The game is drawn in two layers, so the canvas layout has to measure the HTML HUD (below). |
| **Play field laid out below the measured HUD** | `resize()` reads where the score and combo line end and fits the orbits, with hazard glow, into the space below. At 844×390, 667×375, 1024×600, 1280×720, 1366×768, 390×844 and 1440×900, no hazard can pass under the HUD or below the screen. Short landscape screens also get a smaller score (40 px). | On short landscape screens the field is smaller than the full height would allow, and the orbits sit a little below the centre of the screen. |
| **Phase banner and first-run hint moved off the field** | The "SPEED UP" banner is drawn inside the singularity, where no hazard ever passes. The first-run hint uses the combo line. Neither can cover play or fall off-screen at any size. | The banner is smaller than a full-width title card would be. It reads as a pop of the core, not as a separate screen. |
| **Fake glow from cached sprites with additive blending** (not `shadowBlur`) | `shadowBlur` drops frame rate badly on phones. Sprites keep hundreds of particles at 60 fps. | The glow is a fixed radial falloff, so it can't bloom based on the scene. |
| **Two orbits and one input** | Easy to learn in 2 seconds, playable one-handed on a phone, and tight for "one more run". | Fewer verbs. The game gets its depth from rhythm, greed (combo vs. safety) and close-call risk, not from extra controls. |
| **Spacing and reading time measured in seconds, not angle** | Stays fair at every speed (see the table above). | At top speed a new hazard pops in about a third of a lap behind your core, coming round the loop. You see it earlier, but it is placed less obviously "ahead". Patterns also look more spread out on screen at high speed. |
| **Close calls based on the orbit you actually left** (not on when you last pressed) | Risk-free input chords can't farm points or the Daredevil achievement. | Quickly going onto a mine's orbit and back off it, just before the mine, does count. That is deliberate: for those frames you really were on the mine's orbit. |
| **LocalStorage only** | No backend and works offline, as required. | Progress is per browser and per device. Clearing site data wipes it, and there are no online leaderboards. Where the browser blocks storage, nothing can persist; the game can only tell you so, which it does. |
| **Re-read the save before every write** (not a merge of two divergent copies) | Simple and correct, because every change is written the moment it happens. No tab ever holds unsaved progress for long. | If two tabs finish a run in the same millisecond, one run's shards could be counted from a slightly stale read. In practice this cannot happen by hand. |
| **Abandoned runs bank their score and shards, but count toward *Runs* only after 5 s** | You never lose a new best or shards you collected because you quit, and spamming `R` can't farm the 25-run achievement. | A real but very short run that you quit (under 5 s) is not counted in *Runs*. Deaths always count, however short. |
| **Retry skips the death sequence after 0.4 s** (rather than waiting for the result card) | A run is 0.4 s from death to replay when you want it. The full slow-motion and card still play if you don't press anything. | If you press during the slow-motion you don't see the result card. The HUD's *Best* updates and a new best gets a "New best!" toast, but you don't see that run's top combo and shard total. A tap in the first 0.4 s is ignored. |
| **Screen-reader support covers status, not play** | The HUD is readable by screen readers while you play. A polite live region speaks multiplier gains, phase changes, shield events, lost combos and the final score, but not every shard, which would drown the reader. Menus, Hangar and buttons are labelled and keyboard-operable. | A reflex game that depends on seeing hazards is still not playable without sight. This gives blind and low-vision players the numbers, not the play. |
| **Another tab's core and mute choices wait until the run ends** | The live run never changes its look or sound because of something done elsewhere. | A mute pressed in another tab does not silence a run already going here. Press `M` in this tab for that. |
| **System font stack** | No network requests, and nothing shifts while a web font loads. | The type looks slightly different on each OS. |

## Assumptions

- The skills you named aren't available here. I applied what their names describe directly: a deliberate visual system, accessible UI (labelled, keyboard-operable controls and screen-reader announcements of score events), and complete production code with no TODOs.
- "Self-contained" means one file you open directly. Phaser, Three.js and React were allowed but not required, so I left them out (see the trade-offs).
- Browsers block audio until you interact with the page. The sound engine starts on your first tap, click or key press, and music begins once the audio context is running. If the browser refuses to create audio at all (privacy settings, too many audio contexts), the error is caught and the game runs silently. A tap always starts the run.
- `prefers-reduced-motion` is respected: screen shake drops to 25%, flashes are dimmed, and CSS animations are turned off.

## What I tested

All tests ran in headless Chromium (Playwright) against a test copy of the file. The copy differs by one line, added just before `resize();` near the end of the script, which exposes internals for the scripts:

```js
window.__t = { G, get mode(){return mode}, snapLane, Save, CFG, view, startRun, skin, Sound, get time(){return time}, die:(x,y)=>die(x,y) };
```

**Core flows** (390×844 touch and 1440×900): no console errors; menu → play → death → result card → tap or Space to retry; pause and resume, and returning to the menu; mute is saved; achievements unlock and show a toast during a run; buying and equipping a core in the Hangar updates the save; the save survives a page reload.

**Restart and keyboard checks** (1280×720), with results:
- **Enter on a fresh title screen** (nothing focused) starts a run.
- **Skipping the death sequence:** after a forced death, `Space` at 0.15 s is ignored (still dying); `Space` at about 0.5 s starts a new run, and the dead run is already in the save (*Runs* 1, *Best* 50). A canvas tap at 0.45 s after a death also starts a new run. Waiting 1.3 s shows the result card, where `Enter` retries.
- **Random tapping on a 390×844 touch screen** for 120 taps with tap-to-skip after each death: 6 deaths, 6 runs counted, no errors.
- **Screen reader:** the HUD has `aria-hidden="false"` while playing and `"true"` on the menus. When the result card opens, the live region reads "Run over. Score 0."

**Exploit and input checks**, with results:
- **Close-call chord:** a mine is placed 0.15 rad ahead on the other orbit, then `snapLane()` is called twice in one frame. Result: 0 close calls, 0 points. The same test with `W` then `S` pressed back to back gives 0 close calls. A real single dodge off the mine's own orbit gives 1 close call, and the player survives.
- **Caps Lock / Shift:** `Shift+W` during play switches orbit.
- **`R` spam:** 26 presses of `R` mid-run leave *Runs* at 0, and no achievement unlocks. A run that lasted 6 s and was then quit with `R` adds 1 to *Runs*.
- **Keyboard on the result card:** after a death, focus is on *Play again*. `Tab` moves to *Hangar*, and `Enter` opens the Hangar (the game stays on the result screen and no run starts). `Esc` returns. `Space` on a focused *Menu* goes to the menu. On the main menu, `Space` on a focused *Hangar & Achievements* opens the Hangar. With no button focused, `Space` starts a run.
- **Layout:** at the 7 viewports listed in the trade-offs, the top of the outer orbit, glow included, is below the bottom of the HUD's combo line, and the bottom of the orbit is inside the screen. For example, at 844×390 the HUD ends at y = 73 and the field starts at y = 82. At 1366×768 the field ends at y = 753, inside the 768 px screen. Screenshots of the phase-2 banner at 844×390 and 1366×768 show "SPEED UP 2" inside the singularity.

**Fairness bot.** The bot below is injected after pressing Play. At phase 1 it survived 100 s and reached phase 6. Forced to phase 12, it survived 40 s at 3.7 rad/s. The shortest reading time it measured after the first 3 s was 1.13 s:

```js
const t = window.__t, G = t.G; window.__minRead = 99; const seen = new WeakSet();
setInterval(() => {
  if (t.mode !== 1) return;
  for (const e of G.entities) if (!seen.has(e)) { seen.add(e); window.__minRead = Math.min(window.__minRead, (e.at - G.angle) / G.speed); }
  const ahead = G.entities.filter(e => !e.resolved && e.at > G.angle);
  const nm = l => { const m = ahead.filter(e => e.type === "mine" && e.lane === l).map(e => e.at - G.angle); return m.length ? Math.min(...m) : 99; };
  const cur = nm(G.lane), oth = nm(1 - G.lane);
  if (cur < 0.25 && oth > cur + 0.05) t.snapLane(); // dodge only when the next mine on this orbit is close
}, 8);
```

**Failure cases:**
- **Death-time save:** the save shows the finished run about 880 ms *before* the result card appears.
- **Two tabs:** another tab changed the bank to 999 and added a core. The open Hangar in this tab updated to "999 shards" at once. A run then ended in the first tab, and the core was still owned.
- **Two tabs, mid-run:** while a run was going in tab A, tab B owned and equipped *Void*, muted, and set the bank to 999. Tab A adopted the 999 bank at once but kept the *Ion* core and its sound for the rest of the run. After that run died, tab A showed *Void*, was muted, and the mute button read "Unmute sound". *Void* was still owned in storage.
- **Storage blocked** (`getItem`/`setItem` throw `SecurityError`): the red notice shows on the menu, and Play still works.
- **`AudioContext` constructor throws:** Play starts the run, and taps and `M` cause no errors.
- **Forced render crash** (`arc()` made to throw for 100 ms mid-run): the game saved the run, went back to the menu, showed a "Something went wrong" toast, and was playable again right away.

Across all of these there were no uncaught errors.

**How a failing frame is handled.** Testing found one crash and I fixed it. The pop-in easing curve could return a tiny negative number, and `arc()` throws an error on a negative radius, so the easing is now clamped at 0. As a general safeguard, each frame's update and render run inside a `try/catch`. When a frame fails, the game resets the canvas state, skips that frame and logs the error. If three frames in a row fail, the state itself is assumed to be broken: the current run is saved, the game resets to the menu, and a one-time notice appears. A repeated error therefore cannot leave a frozen screen.

    this.tone({ f: 160, to: 30, dur: 0.8, type: "sine", vol: 0.6 });
    this.tone({ f: 90, to: 40, dur: 0.6, type: "sawtooth", vol: 0.12, at: 0.02 });
  },
  ui()          { this.tone({ f: 660, dur: 0.05, type: "sine", vol: 0.08 }); },
  buy()         { [0, 4, 7, 11, 14].forEach((s, i) => this.tone({ f: 523 * Math.pow(2, s / 12), dur: 0.18, type: "triangle", vol: 0.12, at: i * 0.05 })); },
  deny()        { this.tone({ f: 180, dur: 0.15, type: "square", vol: 0.07 }); this.tone({ f: 150, dur: 0.15, type: "square", vol: 0.07, at: 0.1 }); },

  // --- Procedural music: kick + hats + pentatonic bass, tempo follows phase ---
  startMusic() { this.musicOn = true; this.musicReset = true; }, // actual start happens in pumpMusic once the context runs
  stopMusic() {
    this.musicOn = false;
    if (this.ok()) this.music.gain.setTargetAtTime(0, this.ctx.currentTime, 0.15);
  },
  pumpMusic() {
    if (!this.musicOn || !this.ok()) return;
    if (this.musicReset) {
      this.musicReset = false; this.beat = 0; this.kicks.length = 0;
      this.nextBeat = this.ctx.currentTime + 0.05;
      this.music.gain.cancelScheduledValues(this.ctx.currentTime);
      this.music.gain.setTargetAtTime(0.55, this.ctx.currentTime, 0.2);
    }
    const spb = 60 / this.bpm / 2; // eighth notes
    const bass = [0, 0, 7, 0, 10, 0, 7, 5];
    while (this.nextBeat < this.ctx.currentTime + 0.12) {
      const at = this.nextBeat - this.ctx.currentTime;
      const b = this.beat;
      if (b % 2 === 0) {
        this.tone({ f: 140, to: 42, dur: 0.18, type: "sine", vol: 0.55, at, out: this.music });
        this.kicks.push(this.nextBeat); if (this.kicks.length > 4) this.kicks.shift();
      }
      else this.noise({ dur: 0.04, vol: 0.12, freq: 8000, type: "highpass", at, out: this.music });
      const bar = Math.floor(b / 8) % 4;
      const root = [0, -4, 3, -2][bar];
      if (b % 2 === 1) this.tone({ f: 55 * Math.pow(2, (bass[b % 8] + root) / 12), dur: spb * 0.9, type: "sawtooth", vol: 0.07, at, attack: 0.01, out: this.music });
      this.beat++;
      this.nextBeat += spb;
    }
  },
  // 0..1 envelope of the most recent kick that has actually sounded (drives the core pulse)
  kickPulse() {
    if (!this.musicOn || !this.ok()) return -1;
    const now = this.ctx.currentTime;
    for (let i = this.kicks.length - 1; i >= 0; i--) if (this.kicks[i] <= now) return Math.exp(-(now - this.kicks[i]) * 9);
    return 0;
  }
};

const glowCache = new Map();
function glow(color) {
  let c = glowCache.get(color);
  if (c) return c;
  c = document.createElement("canvas"); c.width = c.height = 128;
  const g = c.getContext("2d");
  const grd = g.createRadialGradient(64, 64, 0, 64, 64, 64);
  grd.addColorStop(0, color); grd.addColorStop(0.25, color + "aa"); grd.addColorStop(1, color + "00");
  g.fillStyle = grd; g.fillRect(0, 0, 128, 128);
  glowCache.set(color, c);
  return c;
}
function drawGlow(color, x, y, r, a = 1) {
  ctx.globalAlpha = a;
  ctx.drawImage(glow(color), x - r, y - r, r * 2, r * 2);
  ctx.globalAlpha = 1;
}
const hsl = (h, s, l) => `hsl(${h},${s}%,${l}%)`;
function hslHex(h, s, l) {
  s /= 100; l /= 100;
  const k = n => (n + h / 30) % 12, a = s * Math.min(l, 1 - l);
  const f = n => l - a * Math.max(-1, Math.min(k(n) - 3, Math.min(9 - k(n), 1)));
  return "#" + [f(0), f(8), f(4)].map(x => Math.round(x * 255).toString(16).padStart(2, "0")).join("");
}
const lerp = (a, b, t) => a + (b - a) * t;
const clamp = (v, a, b) => Math.max(a, Math.min(b, v));
const rand = (a, b) => a + Math.random() * (b - a);
const easeOutBack = t => Math.max(0, 1 + 2.70158 * Math.pow(t - 1, 3) + 1.70158 * Math.pow(t - 1, 2)); // never negative: arc() throws on r < 0
const TAU = Math.PI * 2;

/* Background stars: three depth layers that drift with the player's orbit */
let stars = [];
function makeStars() {
  const n = Math.round(clamp(view.w * view.h / 9000, 60, 220));
  const R = Math.hypot(view.w, view.h) / 2 + 20;
  stars = [];
  for (let i = 0; i < n; i++) {
    const d = Math.sqrt(Math.random());
    stars.push({ a: Math.random() * TAU, r: d * R, z: rand(0.2, 1), tw: Math.random() * TAU });
  }
}

const FX = {
  parts: [], rings: [], texts: [], trauma: 0, flash: 0, flashColor: "#ffffff",
  burst(x, y, color, n, speed = 260, life = 0.6, size = 3) {
    for (let i = 0; i < n && this.parts.length < 700; i++) {
      const a = Math.random() * TAU, s = speed * (0.3 + Math.random() * 0.7);
      this.parts.push({ x, y, vx: Math.cos(a) * s, vy: Math.sin(a) * s, life, max: life, size: size * rand(0.6, 1.3), color });
    }
  },
  ring(x, y, color, maxR = 60, life = 0.45, width = 3) { this.rings.push({ x, y, color, maxR, life, max: life, width }); },
  text(x, y, str, color = "#ffffff", size = 18) { this.texts.push({ x, y, str, color, size, life: 0.9, max: 0.9 }); },
  shake(amount) { this.trauma = Math.min(1, this.trauma + amount * (reducedMotion ? 0.25 : 1)); },
  doFlash(color, a) { this.flashColor = color; this.flash = Math.max(this.flash, a * (reducedMotion ? 0.4 : 1)); },
  update(dt) {
    for (let i = this.parts.length - 1; i >= 0; i--) {
      const p = this.parts[i];
      p.life -= dt;
      if (p.life <= 0) { this.parts[i] = this.parts[this.parts.length - 1]; this.parts.pop(); continue; }
      p.vx *= Math.pow(0.04, dt); p.vy *= Math.pow(0.04, dt);
      p.x += p.vx * dt; p.y += p.vy * dt;
    }
    for (let i = this.rings.length - 1; i >= 0; i--) { if ((this.rings[i].life -= dt) <= 0) this.rings.splice(i, 1); }
    for (let i = this.texts.length - 1; i >= 0; i--) { const t = this.texts[i]; t.y -= 40 * dt; if ((t.life -= dt) <= 0) this.texts.splice(i, 1); }
    this.trauma = Math.max(0, this.trauma - dt * 1.6);
    this.flash = Math.max(0, this.flash - dt * 3);
  },
  shakeOffset(time) {
    const s = this.trauma * this.trauma * 18;
    return { x: s * Math.sin(time * 91.3) * Math.cos(time * 37.1), y: s * Math.cos(time * 77.7) * Math.sin(time * 53.9), r: this.trauma * this.trauma * 0.03 * Math.sin(time * 41) };
  },
  draw() {
    ctx.globalCompositeOperation = "lighter";
    for (const p of this.parts) {
      const k = p.life / p.max;
      drawGlow(p.color, p.x, p.y, p.size * 3 * (0.5 + k), k);
    }
    for (const r of this.rings) {
      const k = 1 - r.life / r.max, e = 1 - Math.pow(1 - k, 3);
      ctx.strokeStyle = r.color; ctx.globalAlpha = (1 - k) * 0.9; ctx.lineWidth = r.width * (1 - k) + 0.5;
      ctx.beginPath(); ctx.arc(r.x, r.y, r.maxR * e, 0, TAU); ctx.stroke();
    }
    ctx.globalAlpha = 1;
    ctx.globalCompositeOperation = "source-over";
    ctx.textAlign = "center"; ctx.textBaseline = "middle";
    for (const t of this.texts) {
      const k = t.life / t.max, pop = k > 0.8 ? easeOutBack((1 - k) / 0.2) : 1;
      ctx.globalAlpha = Math.min(1, k * 2);
      ctx.font = `800 ${t.size * pop}px ${FONT}`;
      ctx.fillStyle = t.color; ctx.fillText(t.str, t.x, t.y);
    }
    ctx.globalAlpha = 1;
  },
  clear() { this.parts.length = 0; this.rings.length = 0; this.texts.length = 0; this.trauma = 0; this.flash = 0; }
};

/* =========================================================================
   7. SPAWNING: patterns are laid out along the unwrapped angle,
      spaced in *time* so they stay fair as speed rises.

function spacing() {
  const t = lerp(CFG.spacingStart, CFG.spacingMin, clamp((G.phase - 1) / 7, 0, 1));
  return t * G.speed; // radians between beats of a pattern
}
function add(type, lane, at) { G.entities.push({ type, lane, at, born: time, dead: false, spin: Math.random() * TAU }); }

const PATTERNS = {
  // shards on a lane, mine on the other. Teaches the core read.
  pair(at, s) {
    const l = Math.random() < 0.5 ? 0 : 1;
    for (let i = 0; i < 3; i++) add("shard", l, at + i * s * 0.6);
    add("mine", 1 - l, at + s * 0.6);
    return s * 1.6;
  },
  // alternating mines, shards tucked opposite: rhythm game feel
  slalom(at, s) {
    let l = Math.random() < 0.5 ? 0 : 1;
    const n = 3 + Math.min(3, Math.floor(G.phase / 2));
    for (let i = 0; i < n; i++) { add("mine", l, at + i * s); add("shard", 1 - l, at + i * s); l = 1 - l; }
    return n * s;
  },
  // a long wall of mines with a reward line beside it
  wall(at, s) {
    const l = Math.random() < 0.5 ? 0 : 1;
    const n = 4 + Math.min(4, G.phase);
    for (let i = 0; i < n; i++) { add("mine", l, at + i * s * 0.5); if (i % 2 === 0) add("shard", 1 - l, at + i * s * 0.5); }
    return n * s * 0.5;
  },
  // free shards that tempt you across: combo bait
  bait(at, s) {
    const l = Math.random() < 0.5 ? 0 : 1;
    for (let i = 0; i < 4; i++) add("shard", l, at + i * s * 0.55);
    add("mine", l, at + 4 * s * 0.55 + s * 0.5);
    for (let i = 0; i < 2; i++) add("shard", 1 - l, at + 4 * s * 0.55 + s * 0.5 + i * s * 0.55);
    return 6 * s * 0.55 + s * 0.5;
  },
  // two mines with a one-beat gap: requires a double tap
  zigzag(at, s) {
    const l = Math.random() < 0.5 ? 0 : 1;
    add("mine", l, at); add("shard", 1 - l, at);
    add("mine", 1 - l, at + s * 1.1); add("shard", l, at + s * 1.1);
    add("mine", l, at + s * 2.2); add("shard", 1 - l, at + s * 2.2);
    return s * 2.2;
  }
};
function spawn() {
  // At max speed (3.7 rad/s) this is 4.26 rad, so reading time never drops below 1.15 s.
  const look = clamp(CFG.lookaheadTime * G.speed, CFG.lookaheadMin, CFG.lookaheadMax);
  while (G.spawnAt < G.angle + look) {
    const s = spacing();
    if (!G.shield && Math.random() < CFG.shieldChance && G.phase >= 2) {
      add("shield", Math.random() < 0.5 ? 0 : 1, G.spawnAt);
      G.spawnAt += s * 1.2;
      continue;
    }
    const pool = G.phase < 2 ? ["pair", "pair", "bait", "slalom"] :
                 G.phase < 4 ? ["pair", "slalom", "wall", "bait", "zigzag"] :
                               ["slalom", "slalom", "wall", "bait", "zigzag", "zigzag"];
    let name;
    do { name = pool[(Math.random() * pool.length) | 0]; } while (name === G.lastPattern && pool.length > 1 && Math.random() < 0.7);
    G.lastPattern = name;
    const len = PATTERNS[name](G.spawnAt, s);
    G.spawnAt += len + s * rand(1.1, 1.6); // breathing room between patterns
  }
}

// Writes a finished (or abandoned) run to the save exactly once.
function commitRun() {
  if (G.committed || G.runTime <= 0) return; // runTime 0 = the idle menu orbit, not a real run
  G.committed = true;
  Save.refresh();
  const d = Save.data;
  // A death always counts; an abandoned run counts only once it lasted minCountedRun,
  // so spamming R cannot farm the Runs total (or the achievement tied to it).
  if (mode === MODE.DYING || G.runTime >= CFG.minCountedRun) d.runs++;
  G.isBest = G.score > 0 && G.score > d.best;
  if (G.score > d.best) d.best = G.score;
  d.bestCombo = Math.max(d.bestCombo, G.maxCombo);
  d.bank += G.shards; d.totalShards += G.shards;
  Save.write();
  checkAchievements();
  refreshMenu();
}

function phaseUp() {
  G.phase++;
  G.speed = Math.min(CFG.maxSpeed, G.speed + CFG.speedPerPhase);
  G.phaseFlash = 1.6;
  Sound.bpm = Math.min(150, 112 + (G.phase - 1) * 5);
  Sound.phaseUp();
  announce(`Speed up. Phase ${G.phase}. Score ${fmt(G.score)}.`);
  FX.ring(view.cx, view.cy, hslHex(phaseHue(), 90, 65), view.unit * 0.7, 0.9, 5);
  FX.shake(0.15);
  checkAchievements();
}

function checkAchievements() {
  for (const a of ACHIEVEMENTS) {
    if (Save.data.ach.includes(a.id)) continue;
    if (a.test(G, Save.data)) {
      Save.refresh();
      if (Save.data.ach.includes(a.id)) continue; // another tab got there first
      Save.data.ach.push(a.id);
      Save.data.bank += a.reward;
      G.earned.push(a.id);
      Save.write();
      Sound.buy();
      toast(`Achievement: ${a.name}`, `+${a.reward} shards`);
    }
  }
}

/* =========================================================================
   9. UPDATE
   ========================================================================= */
function update(dt) {
  time += dt;
  if (hitstop > 0) { hitstop -= dt; FX.update(dt * 0.2); return; }

  if (mode === MODE.DYING) {
    const k = clamp((time - G.dieAt) / CFG.deathDelay, 0, 1);
    timeScale = lerp(0.15, 1, k);
    FX.update(dt * timeScale);
    if (time - G.dieAt > CFG.deathDelay) gameOver();
    return;
  }
  timeScale = 1;
  FX.update(dt);

  if (mode === MODE.MENU || mode === MODE.OVER) {
    // attract mode: player idles on the outer ring
    G.angle += dt * 0.9;
    G.radiusT = 0.5 + Math.sin(time * 1.3) * 0.5;
    pushTrail();
    return;
  }
  if (mode !== MODE.PLAY) return;

  G.runTime += dt;
  if (G.runTime > G.phase * CFG.phaseLength) phaseUp();
  G.phaseFlash = Math.max(0, G.phaseFlash - dt);
  G.invuln = Math.max(0, G.invuln - dt);

  const prevAngle = G.angle;
  G.angle += G.speed * dt;
  const target = G.lane;
  const step = dt / CFG.laneSwitchTime;
  G.radiusT = target > G.radiusT ? Math.min(target, G.radiusT + step) : Math.max(target, G.radiusT - step);
  // The collision test below calls you "on" an orbit once you are past the halfway radius.
  // Track when that actually changes: two taps in one frame never move you, so they never count.
  const side = G.radiusT >= 0.5 ? 1 : 0;
  if (side !== G.side) { G.leftLane = G.side; G.leftAt = G.runTime; G.side = side; }
  pushTrail();
  spawn();

  // crossing test: each entity resolves the frame the player passes its angle
  const pr = playerRadius();
  const laneGap = view.rOut - view.rIn;
  for (const e of G.entities) {
    if (e.dead || e.resolved) continue;
    if (e.at > G.angle || e.at <= prevAngle - 0.0001) {
      if (e.at <= prevAngle - 0.0001) e.resolved = true; // spawned behind (should not happen)
      continue;
    }
    e.resolved = true;
    const er = e.lane ? view.rOut : view.rIn;
    const x = view.cx + Math.cos(e.at) * er, y = view.cy + Math.sin(e.at) * er;
    const sameLane = Math.abs(pr - er) < laneGap * 0.5;
    if (e.type === "shard") { if (sameLane) { e.dead = true; collectShard(e, x, y); } else missShard(e, x, y); }
    else if (e.type === "shield") { if (sameLane) { e.dead = true; grabShield(e, x, y); } }
    else if (e.type === "mine") {
      if (sameLane) { hitMine(e, x, y); if (mode !== MODE.PLAY) return; }
      // only a real dodge pays: the core must have actually left this mine's orbit, just now
      else if (G.leftLane === e.lane && G.runTime - G.leftAt < CFG.closeCallWindow) closeCall(x, y);
    }
  }
  // drop entities well behind the player
  G.entities = G.entities.filter(e => G.angle - e.at < 0.6);

  // score counter eases toward the real score
  if (G.shown !== G.score) {
    G.shown = G.score - G.shown < 2 ? G.score : Math.ceil(lerp(G.shown, G.score, Math.min(1, dt * 14)));
    ui.score.dirty = true;
  }
  Sound.pumpMusic();
}

function pushTrail() {
  const p = playerPos();
  G.trail.unshift({ x: p.x, y: p.y });
  if (G.trail.length > 26) G.trail.length = 26;
}

/* =========================================================================
   10. RENDER
   ========================================================================= */
function render() {
  const { w, h, cx, cy } = view;
  ctx.setTransform(view.dpr, 0, 0, view.dpr, 0, 0);
  const hue = phaseHue();

  // background
  ctx.fillStyle = "#07060d"; ctx.fillRect(0, 0, w, h);
  const bg = ctx.createRadialGradient(cx, cy, 0, cx, cy, Math.max(w, h) * 0.75);
  bg.addColorStop(0, hsl(hue, 60, 12)); bg.addColorStop(0.5, hsl(hue, 50, 6)); bg.addColorStop(1, "#05040a");
  ctx.fillStyle = bg; ctx.fillRect(0, 0, w, h);

  const sh = FX.shakeOffset(time);
  ctx.save();
  ctx.translate(cx + sh.x, cy + sh.y); ctx.rotate(sh.r); ctx.translate(-cx, -cy);

  // stars drift opposite to the orbit for parallax
  const drift = -G.angle * 0.06;
  for (const s of stars) {
    const a = s.a + drift * s.z;
    const x = cx + Math.cos(a) * s.r, y = cy + Math.sin(a) * s.r;
    const tw = 0.5 + 0.5 * Math.sin(time * 2 + s.tw);
    ctx.globalAlpha = (0.25 + 0.55 * tw) * s.z;
    ctx.fillStyle = "#cfd6ff";
    ctx.fillRect(x, y, s.z * 1.8, s.z * 1.8);
  }
  ctx.globalAlpha = 1;

  // core: pulses on the beat
  const kp = Sound.kickPulse();
  const beatPulse = kp >= 0 ? kp : 0.3 + 0.3 * Math.sin(time * 2);
  ctx.globalCompositeOperation = "lighter";
  drawGlow(hslHex(hue, 90, 60), cx, cy, view.rIn * (0.95 + beatPulse * 0.12), 0.55);
  ctx.globalCompositeOperation = "source-over";
  ctx.fillStyle = "#0b0916";
  ctx.beginPath(); ctx.arc(cx, cy, view.rIn * 0.42, 0, TAU); ctx.fill();
  ctx.strokeStyle = hsl(hue, 90, 70); ctx.lineWidth = 2; ctx.globalAlpha = 0.7 + beatPulse * 0.3;
  ctx.beginPath(); ctx.arc(cx, cy, view.rIn * (0.42 + beatPulse * 0.03), 0, TAU); ctx.stroke();
  ctx.globalAlpha = 1;

  // Phase number inside the core. On a phase change it doubles as the "speed up" banner:
  // the label switches and the number pops. Nothing ever passes through the core, so the
  // banner can't cover a hazard or fall off-screen at any viewport size.
  ctx.textAlign = "center"; ctx.textBaseline = "middle";
  if (mode === MODE.PLAY || mode === MODE.DYING || mode === MODE.PAUSE) {
    const flashing = G.phaseFlash > 0 && mode === MODE.PLAY;
    const k = flashing ? G.phaseFlash / 1.6 : 0;          // 1 -> 0 over the banner
    const pop = flashing ? 1 + 0.55 * Math.pow(k, 2) : 1;
    ctx.fillStyle = flashing ? hsl(hue, 90, 75) : hsl(hue, 40, 70);
    ctx.globalAlpha = flashing ? 0.95 : 0.5;
    ctx.font = `${flashing ? 800 : 700} ${Math.round(view.unit * 0.026)}px ${FONT}`;
    ctx.fillText(flashing ? "SPEED UP" : "PHASE", cx, cy - view.unit * 0.03 * pop);
    ctx.globalAlpha = 0.9; ctx.fillStyle = flashing ? hsl(hue, 100, 88) : "#ffffff";
    ctx.font = `800 ${Math.round(view.unit * 0.07 * pop)}px ${FONT}`;
    ctx.fillText(G.phase, cx, cy + view.unit * 0.022 * pop);
    ctx.globalAlpha = 1;
  }

  // orbits
  for (const [r, lane] of [[view.rIn, 0], [view.rOut, 1]]) {
    const active = mode === MODE.PLAY && G.lane === lane;
    ctx.strokeStyle = active ? hsl(hue, 80, 75) : hsl(hue, 40, 55);
    ctx.globalAlpha = active ? 0.45 : 0.18;
    ctx.lineWidth = active ? 2 : 1.5;
    ctx.beginPath(); ctx.arc(cx, cy, r, 0, TAU); ctx.stroke();
    // moving ticks
    ctx.globalAlpha = active ? 0.5 : 0.22;
    const ticks = lane ? 48 : 32;
    for (let i = 0; i < ticks; i++) {
      const a = i / ticks * TAU + time * (lane ? 0.05 : -0.08);
      ctx.beginPath();
      ctx.moveTo(cx + Math.cos(a) * (r - 4), cy + Math.sin(a) * (r - 4));
      ctx.lineTo(cx + Math.cos(a) * (r + 4), cy + Math.sin(a) * (r + 4));
      ctx.stroke();
    }
  }
  ctx.globalAlpha = 1;

  // entities
  const ent = view.unit * 0.022;
  for (const e of G.entities) {
    if (e.dead) continue;
    const r = e.lane ? view.rOut : view.rIn;
    const x = cx + Math.cos(e.at) * r, y = cy + Math.sin(e.at) * r;
    const age = clamp((time - e.born) / 0.3, 0, 1);
    const behind = G.angle - e.at;
    const fade = behind > 0 ? clamp(1 - behind / 0.6, 0, 1) : 1;
    const sc = easeOutBack(age) * (0.6 + 0.4 * fade);
    ctx.save(); ctx.translate(x, y); ctx.globalAlpha = fade;
    if (e.type === "shard") {
      ctx.globalCompositeOperation = "lighter";
      drawGlow("#ffd166", 0, 0, ent * 2.6 * sc, 0.55 * fade);
      ctx.globalCompositeOperation = "source-over";
      ctx.rotate(time * 2.4 + e.spin);
      ctx.fillStyle = "#ffe7a8";
      ctx.beginPath(); ctx.moveTo(0, -ent * sc); ctx.lineTo(ent * 0.65 * sc, 0); ctx.lineTo(0, ent * sc); ctx.lineTo(-ent * 0.65 * sc, 0); ctx.closePath(); ctx.fill();
      ctx.fillStyle = "#ffffff"; ctx.globalAlpha = 0.8 * fade;
      ctx.beginPath(); ctx.moveTo(0, -ent * sc); ctx.lineTo(ent * 0.3 * sc, -ent * 0.1 * sc); ctx.lineTo(0, ent * 0.2 * sc); ctx.closePath(); ctx.fill();
    } else if (e.type === "mine") {
      const pulse = 1 + 0.08 * Math.sin(time * 10 + e.spin);
      ctx.globalCompositeOperation = "lighter";
      drawGlow("#ff4d6d", 0, 0, ent * 3 * sc * pulse, 0.5 * fade);
      ctx.globalCompositeOperation = "source-over";
      ctx.rotate(-time * 3 + e.spin);
      ctx.fillStyle = "#ff4d6d";
      ctx.beginPath();
      const spikes = 8, R = ent * 1.15 * sc * pulse, r0 = ent * 0.6 * sc;
      for (let i = 0; i < spikes * 2; i++) {
        const a = i / (spikes * 2) * TAU, rr = i % 2 ? r0 : R;
        ctx.lineTo(Math.cos(a) * rr, Math.sin(a) * rr);
      }
      ctx.closePath(); ctx.fill();
      ctx.fillStyle = "#2a0710"; ctx.beginPath(); ctx.arc(0, 0, r0 * 0.6, 0, TAU); ctx.fill();
      ctx.fillStyle = "#ffc2cd"; ctx.beginPath(); ctx.arc(0, 0, r0 * 0.25, 0, TAU); ctx.fill();
    } else if (e.type === "shield") {
      ctx.globalCompositeOperation = "lighter";
      drawGlow("#7cf3ff", 0, 0, ent * 3 * sc, 0.6 * fade);
      ctx.globalCompositeOperation = "source-over";
      ctx.rotate(time * 1.5);
      ctx.strokeStyle = "#7cf3ff"; ctx.lineWidth = 2.5;
      ctx.beginPath();
      for (let i = 0; i < 6; i++) { const a = i / 6 * TAU; ctx.lineTo(Math.cos(a) * ent * 1.2 * sc, Math.sin(a) * ent * 1.2 * sc); }
      ctx.closePath(); ctx.stroke();
      ctx.fillStyle = "#d9fbff"; ctx.beginPath(); ctx.arc(0, 0, ent * 0.35 * sc, 0, TAU); ctx.fill();
    }
    ctx.restore();
  }

  // player trail + body
  {
    const showPlayer = mode !== MODE.DYING;
    if (showPlayer && G.trail.length > 1) {
      ctx.globalCompositeOperation = "lighter";
      ctx.lineCap = "round";
      const pr = view.unit * 0.022;
      for (let i = 1; i < G.trail.length; i++) {
        const k = 1 - i / G.trail.length;
        ctx.strokeStyle = trailColor(i / G.trail.length);
        ctx.globalAlpha = k * 0.85;
        ctx.lineWidth = pr * 1.6 * k + 0.5;
        ctx.beginPath(); ctx.moveTo(G.trail[i - 1].x, G.trail[i - 1].y); ctx.lineTo(G.trail[i].x, G.trail[i].y); ctx.stroke();
      }
      ctx.globalAlpha = 1;
      ctx.globalCompositeOperation = "source-over";
    }
    if (showPlayer) {
      const p = playerPos(), s = skin(), pr = view.unit * 0.022;
      const squash = 1 + Math.abs(G.radiusT - G.lane) * 0.6; // stretches while snapping
      ctx.globalCompositeOperation = "lighter";
      drawGlow(trailColor(0), p.x, p.y, pr * 4.5, 0.8);
      ctx.globalCompositeOperation = "source-over";
      ctx.save(); ctx.translate(p.x, p.y); ctx.rotate(G.angle);
      ctx.scale(squash, 1 / squash);
      ctx.fillStyle = s.core; ctx.beginPath(); ctx.arc(0, 0, pr, 0, TAU); ctx.fill();
      ctx.strokeStyle = s.ring || "#ffffff"; ctx.lineWidth = 2; ctx.globalAlpha = 0.9; ctx.stroke();
      ctx.restore(); ctx.globalAlpha = 1;
      if (G.shield && mode === MODE.PLAY) {
        ctx.strokeStyle = "#7cf3ff"; ctx.lineWidth = 2; ctx.globalAlpha = 0.6 + 0.3 * Math.sin(time * 8);
        ctx.beginPath(); ctx.arc(p.x, p.y, pr * 2 + Math.sin(time * 6) * 1.5, 0, TAU); ctx.stroke();
        ctx.globalAlpha = 1;
      }
      if (G.invuln > 0 && Math.floor(time * 20) % 2 === 0) {
        ctx.fillStyle = "#ffffff"; ctx.globalAlpha = 0.6;
        ctx.beginPath(); ctx.arc(p.x, p.y, pr * 1.2, 0, TAU); ctx.fill(); ctx.globalAlpha = 1;
      }
    }
  }

  FX.draw();

  ctx.restore();

  // full-screen flash + vignette (not shaken)
  if (FX.flash > 0) {
    ctx.globalAlpha = FX.flash * 0.5; ctx.fillStyle = FX.flashColor; ctx.fillRect(0, 0, w, h); ctx.globalAlpha = 1;
  }
  const vg = ctx.createRadialGradient(cx, cy, Math.min(w, h) * 0.35, cx, cy, Math.max(w, h) * 0.75);
  vg.addColorStop(0, "rgba(0,0,0,0)"); vg.addColorStop(1, "rgba(0,0,0,0.55)");
  ctx.fillStyle = vg; ctx.fillRect(0, 0, w, h);
}

let runSerial = 0;        // bumps every run, so delayed effects from the last result card can't leak into a new run
function startRun() {
  Sound.unlock();
  commitRun(); // a run abandoned with R or Restart still banks its score and shards
  newRun();
  G.skinId = Save.data.skin;
  runSerial++;
  FX.clear();
  mode = MODE.PLAY;
  hitstop = 0; timeScale = 1;
  Sound.bpm = 112;
  Sound.startMusic();
  ui.score.dirty = true; ui.combo.dirty = true;
  refreshMenu();
  showScreen(null);
  // drop focus so a later Space keyup can't "click" a hidden button and restart the run
  if (document.activeElement && document.activeElement.blur) document.activeElement.blur();
}
function gameOver() {
  mode = MODE.OVER;
  commitRun(); // already done in die(); this is a no-op safety net
  const isBest = G.isBest;
  $("finalScore").textContent = fmt(G.score);
  $("newBest").classList.toggle("on", isBest);
  $("overBest").textContent = fmt(Save.data.best);
  $("overCombo").textContent = fmt(G.maxCombo);
  $("overShards").textContent = `+${fmt(G.shards)}`;
  refreshMenu();
  showScreen("over");
  adoptPrefs();
  announce(`Run over. Score ${fmt(G.score)}.${isBest ? " New best!" : ""}`);
  if (isBest) {
    Sound.phaseUp();
    const serial = runSerial;
    for (let i = 0; i < 4; i++) setTimeout(() => serial === runSerial && mode === MODE.OVER && FX.burst(rand(0, view.w), rand(0, view.h * 0.5), ["#ffd166", "#7cf3ff", "#ff8bf0"][i % 3], 40, 360, 1.2, 3), i * 140);
  }
  G.entities = [];
}
function pause() {
  if (mode !== MODE.PLAY) return;
  mode = MODE.PAUSE;
  Sound.stopMusic();
  showScreen("pause");
}
function resume() {
  if (mode !== MODE.PAUSE) return;
  Sound.unlock();
  mode = MODE.PLAY;
  Sound.startMusic();
  showScreen(null);
  if (document.activeElement && document.activeElement.blur) document.activeElement.blur();
}
function toMenu() {
  commitRun(); // leaving from Pause still banks the run
  mode = MODE.MENU;
  Sound.stopMusic();
  G.entities = []; G.combo = 0;
  adoptPrefs();
  refreshMenu();
  showScreen("menu");
}

canvas.addEventListener("pointerdown", e => {
  e.preventDefault();
  Sound.unlock();
  if (mode === MODE.PLAY) snapLane();
  else retry();

window.addEventListener("keyup", e => { if (e.key === " " && mode === MODE.PLAY) e.preventDefault(); });
window.addEventListener("keydown", e => {
  if (e.repeat) return;
  const k = e.key.length === 1 ? e.key.toLowerCase() : e.key; // W/S/R/P/M work with Caps Lock or Shift
  // Space/Enter on a focused button belong to that button (Hangar, Menu, Resume...), not the game.
  const onButton = document.activeElement && document.activeElement.tagName === "BUTTON";
  const inHangar = ui.screens.hangar.classList.contains("show");
  if (k === "m") { Sound.unlock(); Sound.setMuted(!Sound.muted); updateMuteIcon(); return; }
  if (mode === MODE.PLAY) {
    if (k === " " || k === "ArrowUp" || k === "ArrowDown" || k === "w" || k === "s" || k === "Enter") { e.preventDefault(); snapLane(); }
    else if (k === "Escape" || k === "p") pause();
    else if (k === "r") startRun();
    return;
  }
  if (mode === MODE.DYING) { // skip the death sequence: a key restarts as soon as the guard has passed
    if (k === " " || k === "Enter" || k === "r") { e.preventDefault(); retry(); }
    return;
  }
  if (mode === MODE.PAUSE) {
    if (k === "Escape" || k === "p") resume();
    else if (k === "r") startRun();
    return;
  }
  if (inHangar) { if (k === "Escape") $("hangarBack").click(); return; }
  if (onButton && (k === " " || k === "Enter")) return; // the button's own click handler runs
  if (mode === MODE.OVER && (k === " " || k === "Enter" || k === "r")) {
    e.preventDefault();
    retry();
    return;
  }
  if (mode === MODE.MENU && (k === " " || k === "Enter")) { e.preventDefault(); startRun(); }

let last = performance.now();
let lastScore = 0;
let faults = 0, warnedFault = false;
function frame(now) {
  requestAnimationFrame(frame); // keep the loop alive whatever happens below
  const dt = Math.min(0.033, Math.max(0, (now - last) / 1000));
  last = now;
  try {
    if (mode !== MODE.PAUSE) update(dt);
    render();
    syncHud();
    if (G.score !== lastScore) { if (G.score > lastScore) bumpScore(); lastScore = G.score; }
    faults = 0;
  } catch (err) {
    // A throw mid-render can leave canvas state (alpha, blend mode, transform stack) dirty.
    if (ctx.reset) ctx.reset(); else { ctx.globalAlpha = 1; ctx.globalCompositeOperation = "source-over"; }
    console.error("Orbit Snap: frame failed", err);
    // One bad frame is skipped. If it keeps failing, the state is bad: bank the run and reset.
    if (++faults >= 3) recover();
  }
}
function recover() {
  faults = 0;
  try { commitRun(); } catch (e) { console.error(e); }
  try {
    newRun(); FX.clear();
    hitstop = 0; timeScale = 1; lastScore = 0;
    mode = MODE.MENU;
    Sound.stopMusic();
    refreshMenu(); showScreen("menu");
    if (!warnedFault) { warnedFault = true; toast("Something went wrong", "Your run was saved and the game was reset.", true); }
  } catch (e) { console.error("Orbit Snap: recovery failed", e); }
}
